# Verify Additional Repositories

Read `$CODEINFO_ROOT/codeinfo_markdown/retrospective_story/shared.md` and the selected plan's `### Additional Repositories`. Inspect the work's concrete repository scope. List a repository only when the documented story actually changed it or requires it as an explicit implementation owner. Verify each listed path exists and is a Git repository, and read its `AGENTS.md` before making changes there. Do not infer a repository path from a similar name. Use `- No Additional Repositories` when appropriate. Update `additional_repositories` in the current-plan handoff to match the section, keeping the comparison base and initial HEAD fields intact. For a changed additional repository, establish its own initial HEAD and a supported comparison base in its handoff entry; record an ambiguous base as null and explain the candidates under `### Questions`. Recheck every repository's branch and story number before proceeding; omit an unverifiable repository identity from mutations while continuing with verified scope.
