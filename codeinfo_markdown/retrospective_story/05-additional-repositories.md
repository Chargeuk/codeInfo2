# Verify Additional Repositories

Read `$CODEINFO_ROOT/codeinfo_markdown/retrospective_story/shared.md` and the selected plan's `### Additional Repositories`. Inspect the work's concrete repository scope. List a repository only when the documented story actually changed it or requires it as an explicit implementation owner. Verify each listed path exists and is a Git repository, and read its `AGENTS.md` before making changes there. Do not infer a repository path from a similar name. Use `- No Additional Repositories` when appropriate. Update `additional_repositories` in the current-plan handoff to match the section, keeping the comparison base and initial HEAD fields intact. For a changed additional repository, establish its own explicit comparison base and initial HEAD in its handoff entry; stop on ambiguous identity. Recheck every repository's branch and story number before proceeding.
