# Record one local review batch

Read the immutable batch launch, verified disposition, repair evidence, current Git state for every target repository, and bounded assigned plan. Follow `$CODEINFO_ROOT/codeinfo_markdown/shared/review-artifact-handoff.md` and `$CODEINFO_ROOT/codeinfo_markdown/shared/review-created-task-timestamp.md`. Recover understandable evidence from available artifacts; describe missing or conflicting coverage honestly and never invent a fix, commit, test, or clean result.

Write the batch outcome through its existing `reconciliation/` evidence path, then update the same canonical batch task in the assigned plan. Match by exact immutable batch ID; never duplicate it. Preserve its task number, original `Created`, and finding IDs. Check a finding checkbox only when the outcome evidence establishes its repair; preserve genuinely blocked or unknown accepted items as unchecked. Record focused evidence for every checked item, and state the limitation for every unchecked item. Record the exact repositories and reviewed, repair-start, and current heads when available; fix-bearing state; exact full fix commits and changed files when supported; addressed findings; contributing review/repair work; focused proof and limitations; and batch order/identity needed for later settlement. Keep the preplanned batch task open while any accepted item is genuinely blocked or unknown. Close that same task using the existing `completed_review_fixes` role and `__done__` status only when evidence establishes all accepted fixes; do not create a duplicate completed task. Closeout accounts for already planned open batch work and does not defer it to a new task.

Reopen both outcome and plan task before returning. Repair understandable omissions in this step's owned record only. Do not create a second handoff, task, final-proof task, or additional review/test/record loop. Follow existing Git and ownership rules and the caller's commit boundary.
